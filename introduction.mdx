# LuminOS documentation

LuminOS is a conversion-focused Shopify Online Store 2.0 theme by **Lumintheme**. These docs cover setup, feature guides, and auto-generated section reference pages from the theme schemas.

## What you can do here

- **Getting started** — install, theme editor, and global settings
- **Guides** — deep tutorials for bundles, reviews, quantity breaks, cart, and navigation
- **Sections** — reference pages generated from every theme section and key blocks
- **Troubleshooting** — common failures and fixes
- **Community** — ask questions at [community.lumintheme.com](https://community.lumintheme.com)
