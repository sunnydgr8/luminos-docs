# Frequently bought together

Show a curated add-on set on the product page so shoppers can add multiple items in one click.

## Setup

1. Define the product relationships your theme expects (commonly a product list / reference metafield such as cross-sells — confirm the key in the FBT block settings or [metafields config](https://shopify.dev/docs/apps/build/custom-data)).
2. On each hero product in Admin, fill that metafield with related products.
3. In the theme editor on a product template, enable the **Frequently bought together** block.
4. Adjust headings, price display, and variant pickers in block settings.
5. Preview: selecting variants and Add should add the set to cart.

## Tips

- Prefer 2–3 add-ons; too many reduces conversion.
- Keep add-ons in stock; unavailable items confuse the widget.
- Pair with [Cart drawer](/guides/cart-drawer) recommendations carefully so offers do not compete.

## Still stuck?

Ask in [Setup help](https://community.lumintheme.com/c/setup-help) with the metafield namespace/key you configured.
