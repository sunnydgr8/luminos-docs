# Mix and match bundles

Build a product pool with tiered quantity discounts using the **Lumin Bundle Builder** section. Cart lines use `_lumin_bundle_*` properties (flat cart). Checkout discounts require the [Lumin Discount App](/guides/lumin-discount-app).

## Setup

1. Create or open a page/product template that should host the builder.
2. In the theme editor, **Add section → Lumin Bundle Builder** (or your store’s labeled mix & match section).
3. Add products to the pool and configure tiers (quantity thresholds and percent off labels).
4. Style desktop/mobile sidebars, accents, and slot image ratios in section settings.
5. Install and configure the [Lumin Discount App](/guides/lumin-discount-app) so tier discounts apply at checkout.
6. Preview cart: bundle lines should show the bundle header styling from theme cart settings.

## Cart behavior

- Lines are flat (no nested parent line); properties identify the bundle.
- Theme cart drawer can show a **bundle header** with colors from Theme settings → Cart.
- Without the Discount App, UI tiers still display but checkout may charge full price.

## Tips

- Keep tier quantities clear (for example 3 / 6 / 9).
- Test with a real checkout in a development store before launch.
- See section reference after running `npm run generate` under **Sections**.
