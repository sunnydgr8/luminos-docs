# Sibling products

Sibling products let shoppers jump between related SKUs (colors, scents, kits) without using a single multi-variant product.

## Setup

1. Create a product reference **list metafield** (or use the metafield key expected by the Sibling products block — check block settings).
2. On each product, add the other siblings to that metafield (usually bidirectional).
3. In the product template, enable the **Sibling products** block.
4. Configure labels and option presentation.
5. Preview: selecting a sibling should navigate to that product URL.

## Tips

- Keep sibling sets small and consistent.
- Use clear swatch or label media so differences are obvious.
- Sibling navigation is separate from [FBT](/guides/frequently-bought-together) add-ons.
