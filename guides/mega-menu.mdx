# Mega menu

LuminOS header menus support rich mega menus: tabs, featured products, images, and highlight links.

## Setup

1. Create a **navigation** menu in **Online Store → Navigation** with the link structure you want.
2. Open **Customize → Header**.
3. Configure the header menu block to use that menu.
4. Add mega menu blocks as needed:
   - Tabs / panels
   - Featured products
   - Images / promo cards
   - Highlight links
5. Preview desktop and mobile (drawer append cards may differ from desktop mega panels).

## Tips

- Keep top-level items few; put depth inside tabs.
- Optimize promo images; large media slows the header.
- Test keyboard and touch: drawers on mobile use separate snippets from desktop mega menus.
