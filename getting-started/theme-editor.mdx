# Theme editor basics

LuminOS is an Online Store 2.0 theme: most pages are built from **sections** and nested **blocks**.

## Sections vs blocks

- **Sections** — full-width (or page-width) units you add to a template (hero, FAQ, product information, Lumin Meta Reviews).
- **Blocks** — pieces inside a section (text, buttons, quantity breaks, review stars).

Use **Add section** / **Add block** in the left sidebar of the theme editor.

## Templates

Each template (home, product, collection, page, cart) has its own section stack. Switching templates on a product or page in Admin changes which stack merchants see.

Useful LuminOS templates include product presets and page templates such as bundle, changelog, and theme features.

## Overlay group

Email popup and cart drawer live in the **overlay** / app-like layer (header-adjacent groups), not as ordinary page sections. Look for:

- **Cart drawer** — see [Cart drawer](/guides/cart-drawer)
- **Email popup**

Edits there apply storewide.

## Lumin sections builder

The **Lumin sections** section is a flexible wrapper for composing content blocks quickly on landing pages. Prefer dedicated feature sections (bundle builder, Meta Reviews, FAQ) when you need those behaviors.

## Apps and data

Some blocks expect Shopify data:

- Metaobjects for [Meta Reviews](/guides/meta-reviews)
- Metafields for [siblings](/guides/sibling-products) and [FBT](/guides/frequently-bought-together)
- Apps for [discounts](/guides/lumin-discount-app) and [Kit reviews](/guides/lumin-kit-reviews)
