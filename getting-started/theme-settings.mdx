# Theme settings

Open **Online Store → Themes → Customize → Theme settings** (gear icon). These controls apply across the theme.

## Brand and layout

| Area | What it controls |
| --- | --- |
| Logo and favicon | Header/footer logos, favicon |
| Colors | Color schemes used by sections |
| Typography | Heading and body fonts, scales |
| Page layout | Page width and spacing rhythm |
| Animations | Motion preferences |

## Merchandising UI

| Area | What it controls |
| --- | --- |
| Badges | Sale / sold out / custom badges |
| Buttons | Primary and secondary button styles |
| Input fields | Forms and inputs |
| Popovers and modals | Drawers and dialogs |
| Prices | Price formatting and sale styles |
| Product cards | Card media, content, hover |
| Swatches | Color/image swatch presentation |
| Variant pickers | Pills, dropdowns, and related styles |
| Icons | Icon set preferences |
| Search | Predictive search behavior |

## Cart

Cart theme settings cover drawer vs page behavior, notes, discounts, installments, gift wrap modes, and mix & match cart header styling. Details: [Cart drawer](/guides/cart-drawer) and [Mix and match bundles](/guides/mix-and-match-bundles).

## Social

Add profile URLs used by social link blocks in header/footer.

## Tip

Change one color scheme and preview home + product + cart before publishing. Section-level scheme picks inherit these globals.
