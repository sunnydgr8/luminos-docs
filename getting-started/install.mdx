# Install LuminOS

## From the Shopify Theme Store or zip

1. In Shopify Admin go to **Online Store → Themes**.
2. Add LuminOS (Theme Store) **or** upload the theme zip under **Add theme → Upload zip file**.
3. Open **Customize** on the unpublished theme to configure before going live.
4. When ready, click **Publish**.

## After install

1. Set logo, colors, and typography under **Theme settings** — see [Theme settings](/getting-started/theme-settings).
2. Review the home and product templates in the editor — see [Theme editor](/getting-started/theme-editor).
3. Install companion apps only for features you use:
   - [Lumin Discount App](/guides/lumin-discount-app) for mix & match checkout discounts
   - [Lumin Kit](/guides/lumin-kit-reviews) for app-synced reviews

## Demo templates

LuminOS ships with multiple product and page templates (for example custom, studio, Pro-G, bundle, documentation). Duplicate a template in the theme editor rather than editing the live default until you are happy with the layout.

## Still stuck?

Ask in [Setup help](https://community.lumintheme.com/c/setup-help) with your Shopify plan and whether you installed from the Theme Store or a zip.
